# BigVGAN original CPU inference source

NVIDIA BigVGAN, MIT. Fixed Hugging Face revision `95a9d1dcb12906c03edd938d77b9333d6ded7dfb`; supplemental upstream third-party notices from `7d2b454564a6c7d014227f635b7423881f14bdac`. Selected original Python inference files are byte-identical; CPU execution, no CUDA custom kernel. Source hashes in source-manifest.json. Model weights remain outside Git. No Qixuan bank or artwork is included.

The Qixuan-to-BigVGAN mel-frequency projection is D adapter code, not an upstream claim of compatibility. Weights are not modified. Model-license eligibility and distribution obligations remain separate from mathematical compatibility.
