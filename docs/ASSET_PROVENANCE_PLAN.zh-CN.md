# 资产配方与来源路线

2026-09-08，v7 用户需求；最小配方编解码/隐私投影获准实施，PNG 内嵌、导入界面、全媒体与签名来源尚未开工。本文不是 XMP/IPTC/C2PA 兼容承诺。

## 权威记录与最小闭环

本地项目保存权威历史；媒体携带一次导出快照；数据库仅作可重建索引。格式或体积受限时提供明确 sidecar/交接包，不称为已内嵌。优先当前 PNG：导出内嵌→离开原数据库离线导入→查看来源→恢复为新草稿。原件不覆盖，发布前回读；元数据变化必须验证媒体负载、色彩和方向，不能只靠看图。此闭环不成为全部多模态工作的前置。

本批只完成 D 内部版本化 JSON Data 和公开隐私投影，见 tasks/D-META-RECIPE-01.md。namespace org.d.generation-recipe 是项目内部约定，不是标准命名空间注册或已实现 PNG 嵌入。下一 PNG 包需要按 PNG 规范明确块、命名空间映射、容量、重复/冲突和解压预算，再实现读写，不能先将私有大 JSON 塞进任意字段。

## 身份、真实性和隐私

assetID、assetVersion、生成 runID、物理文件摘要分开；模型来源/revision/权重清单摘要、实际提示/结构化输入版本、适用 seed/调度器/步数/guidance/尺寸、精度/量化/实现版本、派生关系和声明可信度来自执行快照，不从导出时的已变 UI 重读。unknown/not_applicable/withheld/invalid 明确区分；seed 大整数使用十进制字符串，Unicode、单位和时间基显式。物理最终文件全字节摘要不写回自身；媒体负载摘要需定义负载范围，完整文件摘要放外部项目记录。

私有完整归档、协作、公开策略分别设计；首个组件先做私有/公开两种，公开 prompt 默认 withheld，结构化输入版本 withheld、父资产关系明确移除。导出前让人查看实际字段；不能只打“公开”标签。详细硬件/耗时/精确时间可选。密钥、认证头、书签、绝对路径、账号和设备标识不进入普通交接清单。typed allowlist 不等于能扫描出用户任意内容里的所有秘密。

外部数据只解析，不执行工作流/URI，不自动下载或安装依赖，不转为代理指令。限定输入/输出体积、深度、数量、解压和解析预算；未知版本、坏数据、冲突、缺模型要可见。外来 captured 声明不能自动获得信任；声明、签名有效、签名者受信任、内容为真是不同判断。

人类哼唱→AI 转录→人工改谱→模型渲染分别记录。开发 Agent task/run/model/提示及账号配置与用户媒体生成来源完全分域，不加入媒体。T0 稿件等其他模态按适用值填字段，不将不适用参数填零冒充执行事实。
