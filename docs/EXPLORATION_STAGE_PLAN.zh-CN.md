# D-W02 / D-W04a：可持续的视觉探索与比较

日期：2026-09-07。状态：用户已批准实施；起始提交 c39a94d。依据 [总体规划](PRODUCT_STRATEGY.zh-CN.md)。本文是近期工作包，验收结果另行记录。

## 目标与范围

同一项目内独立创作、草稿、候选整理、比较、条件复用、采用与重开。复用现有固定 FLUX.2 后端、模型安装和任务生命周期。不增加参考图推理、局部重绘、新模型、批量、节点、助手、RAW、远程、文档删除或跨文档移动作品。

## 契约与行为

- v2 创作文档拥有稳定身份、名称、草稿、条件复用来源、采用与浏览选择。任务提交快照绑定文档；资产经任务确定归属，不复制媒体。
- 支持新建/重命名/切换、当前/全部作品、名称/收藏/备注及每份创作一张采用版；浏览不隐式采用。
- 从已保存作品复制实际提示词与 seed（含 0）新建创作，保留旧草稿；这不是以原图为输入的编辑。模型/参数不一致或来源不明时明确提示，不声称精确复现。
- 两张项目作品并排比较，适合窗口/100%及同步平移，显示提示词/seed差异；退出回到原选择。比较状态临时，创作选择和整理状态持久。
- 保存绑定发起时文档。切换前 flush，失败阻止切换并保留输入。晚到结果不抢走另一文档的选择。取消/租约/待保存结果/关闭沿用已验收服务。
- v1 全部原始记录归默认文档，不猜测采用/来源。锁内备份原字节并核对后发布 v2，不搬图片；备份失败不迁移；发布中断可重试；未知版本停止写入。保留唯一旧清单和用户文件。
- 服务只传值/ID；UI 使用原生 Liquid Glass 控制和不透明画布，键盘与辅助功能可达。不改推理数学接口或建立新库。
- 候选名称/备注通过绑定固定作品的保存/取消编辑会话处理；未结束编辑前不得由后台结果切换宿主或由关闭/退出丢弃输入。收藏按字段立即保存，不覆盖正在编辑的备注。采用可明确取消。
- 比较期间后台结果仍保存，但不改变比较前选中作品；退出时恢复原选择。观察状态不能成为推理任务所有者。

## 验收

CPU：独立草稿与未完成 seed；延迟保存/准入/结束与切换；保存失败；条件复用不覆盖；候选持久；v1迁移和中断/备份/外部修改/未知版本；媒体哈希不变。应用构建、CPU、UI、真实 GPU 分开记结果。

实机：两份创作至少三次提交，跨文档队列与取消；固定 seed 对照；比较、采用、导出、重开，旧项目安全迁移及磁盘失联。宿主 XCTest 后重新正常签名构建，再验真实沙盒。

检查点：总体规划归档 → 数据/迁移 → UI与真实验收。阶段后再规划参考引导/局部修改，不自动进入远期目标。沿用工作分支和署名，保留用户 Xcode scheme 排序修改。
