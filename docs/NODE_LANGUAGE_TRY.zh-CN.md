## 四套普通、可修改的样例

新建试用项目，进入节点工作台，在顶部 **添加样例** 选择以下四项。每次添加是独立图与工具副本；操作、控制块和工具均可展开编辑，不根据样例名字运行隐藏调度器。

1. **数据与控制（E01，无模型）**：改输入内容/记录成员，在参数表单选字段、筛选和排序；改变列表长度后运行到结果。展开“如果/否则”“逐项”“重复”内部检查普通节点。循环显示初始/下一状态、有限次数与退出原因。非法字段应明确失败；不会自动把列表第一项当结果。
2. **主题与图像批次（E02）**：明确选择上表7B文字模型与 Klein 图像模型，改主题文字，先运行共享规划工具。它用文字模型生成完整主题列表，通过普通数据检查节点，必要时最多修复两次；原始错误文字保留，最终仍非法则停止。1.5B本轮三次输出未满足严格结构，不能保证用它得到六图。默认两主题、每主题三候选，次数只展开一次。看每项的种子/尝试ID/实际模型来源，再选择与处理尺寸格式。添加当前支持的一张参考图时应实际连入参考端口；不要把预览当采用。
3. **哼唱与和声（E03）**：导入有权使用的短单声部录音，或使用明确的录音操作；录音须本人开始。先截取、转换分析规格，再识别连续音高并分段成可编辑音符。此例特意保留两个人工处理点：修正旋律、确认和弦。设固定BPM、拍号与网格，检查普通合成参考音（不是钢琴采样或AI音频），然后明确运行 MRT2 三候选。修改和声保存新版本，再生成比较。原声、识别草稿与修订不覆盖彼此；指定和弦时不暗中调用文字模型建议。
4. **同源四模态（E04）**：同一份已发布文字分向文字、图像、器乐和短 T2V。可逐支运行，不必一次调用全部模型。音乐接的是类型化音符条件，视频接的是文字；不是仅把和弦标题写入prompt，也不伪造视频首帧条件。运行所有分支前先检查各模型绑定和资源预算。本机Wan短片估计13GiB；默认12GiB准入会明确拒绝，本轮通过显式13GiB预算运行。不以开发机容量限制其他Mac的能力，也不自动更改用户预算。

每个节点选中后先看动作，再展开工具/参数，最后查看技术与实际运行记录。当前编辑参数与历史已执行参数不同；编辑不会自动重跑。连线和端口检查显示类型、数量和选定调用的实际值，不能只看参数面板猜运行输入。

## 保存、恢复与导出

项目自动保留产物、来源和检查点；导出是另一个明确操作。保存失败先恢复保存，不要先重新花费推理。正常关闭重开应保留图、工具版本、候选和决定；崩溃恢复只对已落盘检查点负责，未保存的内存不保证无损。
