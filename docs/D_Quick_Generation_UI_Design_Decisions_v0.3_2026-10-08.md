## 0. 本版的地位

本版承接《D_Quick_Generation_UI_Design_Decisions_v0.2_2026-10-07.md》，保留模型能力、任务/素材归属、原生输入、阅读与安全边界，并明确本轮用户新增的布局决议。发生冲突时以本版为准，尤其替换旧右上文字模式入口、侧栏收起占轨和图像/视频结果滚动布局。原 v0.2 留作背景，不要求将其每一个未来例子都做成当前功能。

用户本轮已明确授权：先根据这些意见完成第一版原生界面，之后继续评审细化。此前“只存档、不实施 UI”的阶段限制不再适用于这个明确任务。当前获准转段的基线为 main/candidate 91bef7d7、生产代码8cf1b7dd；这不是正式发行资格，也不是全仓库无缺陷证明。

实现范围：重排现有四模态/节点能力、完善本版明确提出的交互。保留所有已适配能力，不新增模型、训练、远程系统、搜索来源、MIDI编辑器或专业剪辑。F26实际搜索API/凭据继续批准延期。

## 1. 空间骨架与圆形入口

快速生成是中央结果工作面及四周组件；不是自由摆放聊天气泡的无限画布。节点工作流使用现有图画布。

| 区域 | 确定职责 |
|---|---|
| 左上 | 原生红绿灯及可拖动窗口的留白，不自绘系统按钮 |
| 顶部中央 | 文字/图像/视频/音频切换；节点模式不按模态割裂图 |
| 右上 | **相邻两个圆形图标按钮**：工作模式直接切换、统一设置 |
| 左侧 | 下一次请求的模型、操作方式、参数及已适配控制 |
| 右侧 | 素材、候选、结果与相关管理 |
| 底部 | 完整输入组件：已采用材料、文字/歌词等编辑、附件/语音入口、发送/停止 |
| 中央 | 当前查看内容，按模态使用聊天、固定视觉预览或音频播放器 |

模式图标显示当前工作方式，悬停提示说明切换目的；整个圆形区域可点击，含可访问性名称。点击直接切换，不先展开菜单。统一设置在两种模式中位置一致。

左右面板从顶部控制区下方开始。**收起后各只保留一个圆形图标按钮；不保留窄长轨道、文字条或原侧栏宽度的空白。中央列回收释放的空间。**两侧收起时中间工作面使用基本全部可用宽度；正文可以维持合理行长，但不能把整个中央列仍限制在旧宽度。

窄窗口按需折叠，不无限缩小文字和图标。用户手动收起与空间不足临时收起分开；恢复宽度后尊重用户偏好。侧栏、输入组件和常驻操作必须给重要内容留出有效区域，透明度不补救遮挡。

## 2. 中央区域：图像/视频不滚动

图像与视频中央是**固定视口**，不是可滚动的结果文章。不能只隐藏滚动条却继续产生不可达的溢出内容。

- 默认完整适配结果，不变形、不裁切。图像放大后在视口内平移，有缩放及适配入口；不靠页面滚动看大图。
- 视频播放时间轴保留；它不是页面滚动条。预览、播放、候选和主要结果动作在当前有效高度内可达。
- 候选通过前后切换及右侧列表选择，不在中间堆成长结果流。
- 详细参数、长描述和来源进入明确的详情视图，不把预览下方无限拉长。
- 左右参数/资源面板、设置内容与聊天正文仍可正常滚动。本条不禁止一切 ScrollView，也不干扰节点的视图平移。
- 音频先保留当前播放器、进度、候选及模型实际需要的输入；MIDI、音符及其他中间表示的数据不能丢掉，但新的可视化编辑方案以后讨论。

模型切换和候选浏览是不同动作；中央查看旧结果不能悄悄更改左侧下一次配置。明确选择“沿用设置”才复制适用配置。

## 3. 节点工作流：选择、导航和结构编辑

当前源码已有节点卡片 trash、删除的scope/target保护、selectedNodeIDs封装选区及视口导航。以现有实现为起点，不能按旧网页原型遗漏来重写。

### 3.1 删除

每个模型、程序和封装节点都提供直接可达删除图标。只移除图实例和关联连线，不删除模型安装、源素材或历史结果。复用既有撤销和图编辑规则。只读/运行锁定时给出原因，不允许无解释的无效按钮。

### 3.2 指针与手形

| 操作 | 指针模式 | 手形模式 |
|---|---|---|
| 空白处拖动 | 框选节点 | 平移视口 |
| 节点非控件区域拖动 | 移动节点；多选时按既定编辑语义移动 | 以导航为主，不意外改图 |
| 端口拖动/点击 | 连接，检查类型与作用域 | 不意外创建连接 |
| 节点内部按钮/编辑器 | 正常操作，不被外层拖动抢走 | 保留必要明确按钮操作，文本焦点受保护 |
| 放大/缩小/触控板 | 保留已有可靠行为 | 保留已有可靠行为 |

指针可以框选并通过现有封装机制创建自定义节点；封装包含内部图、参数、边界输入输出和相关连接，不能只是视觉分组框。保存、版本和运行由既有图系统负责，不另建编译器。

**右下“恢复/适配视图”只改变缩放和视口位置，不重新排列节点、不重置用户坐标。**保留指针锚定缩放、缩放按钮与既有手势。图内快捷键只在正确焦点下生效，Delete不能在文本编辑时删节点；空格的临时手形不能抢走正常文字空格。

### 3.3 数据类型颜色

同一语义数据类型共享颜色，端口与连线一致；不按节点/模型/候选随机分色。原型配色：文字蓝、图像赭、视频紫、音频绿、音符粉、通用/未决灰。原生按浅深主题调整色号但维持语义。

类型文字、提示和图例保留；颜色不是唯一信息。PNG/JPEG等具体编码显示在详情，不等同全部图像语义。联合类型或未决类型如实显示，不能伪装为已确定单一类型。选中/错误状态用额外标志，不覆写数据的类型含义。

## 4. 统一设置与清晰外观

所有应用级可配置内容集中在右上设置。按语义分类，今后新设置归入相应类别，不不断增加散落入口。

| 类别 | 内容边界 |
|---|---|
| 文件与路径 | 模型库、素材/项目默认位置、缓存等现有配置 |
| 网络 | 当前已实现的下载/网络/代理选项；不虚做设置 |
| API凭证 | 导航到现有安全配置机制；F26延期，不新增密钥平台或要求付费 |
| 语言 | 应用本地化，与模型输出语言不同 |
| 外观 | 浅/深/系统、色号、字号、玻璃透明度、动效、轻量和对比 |
| 操作与辅助 | 已有快捷键、画布交互、可访问性等 |

模型本次推理参数留在左栏；会话/项目范围设置不冒充应用全局偏好。路径变更保留现有授权与原件规则，外观变更不得改写项目或清除凭据。

默认浅色先保证文字可辨。原型色号起点：正文#162F29、辅助#455D54、画布#EDF2EB、底板#FAFCF9、强调#24634F。浅/深主题分别保存自定义色号，提供一键恢复当前主题。低对比自定义可以提示而非永久封锁；默认不能要求用户先开启增强对比才正常阅读。

正文普通文字以4.5:1、重要控件与相邻背景以3:1作为代表检查参考；检查实际合成底色，不把色号计算当整款产品无障碍认证。

聊天气泡可使用Liquid Glass。透明度只影响背景材质，不用整体opacity把字一起抹淡；动效与透明度独立；系统减弱动态效果/降低透明度等偏好优先。轻量外观真正减少昂贵渲染，而非只盖一层不透明颜色。玻璃融合按语义分组，不让不同消息视觉上粘成一条。

## 5. 模型能力决定内容，不改变空间秩序

一份版本化能力契约供节点、Quick、校验和运行共用；展示元数据只管摆放，不另造Quick支持列表。

区分：模型已知能力、当前D适配器实际消费、当前输入/组件是否就绪、已有验证范围。模型支持但D未适配要记适配缺口；后端已承诺能力必须有可达UI；通用参数存在不代表每个模型实际生效。

描述输入的稳定ID、类型、用途、数量/顺序、条件必选和联合规则；同为音频也要区分源音频/风格参考/旋律条件。参数的单位、默认/未指定含义、硬限制与推荐范围分开。模型操作变化时装配必要组件，不把改写/总结等提示模板误拆成独立推理后端。

普通数值/枚举/开关用通用控件；素材角色、歌词、已适配区间等用专用控件。两者编辑同一请求数据、复用同一校验。复杂校验保持在现有适配器，不追求把全部规则写进通用脚本。

换模型只迁移明确兼容的语义，按模型/操作保存其余草稿。不兼容材料保留并明确未采用；隐藏非适用字段不得偷偷进入请求。已提交任务冻结原模型/输入/版本，旧结果按历史事实显示。

工作面不铺满无解释的灰按钮。不支持、未适配、缺组件、不合法、未实测是不同状态。准备/补齐动作可发现，已批准适配缺口不通过文案悄悄取消。

## 6. 行为保护：比材质更优先

- 输入组件内部材料/正文/操作行分开，末行不被按钮覆盖；长输入有适当高度上限；发送/停止固定且标识受控任务。
- 保存草稿、marked text、选区与Undo；视图/主题变化不重建原生输入器。Enter先交输入法，Escape只处理最内层交互。
- 悬停只显示操作，不改变消息高度；点击进入编辑后持久存在。取消恢复原阅读/焦点，未完成编辑不能悄悄丢弃。
- 读旧内容时不被新增消息拉到底；跟底时保持末条；前插历史、展开编辑、侧栏重排和链接取消尽量保持当前可见内容。用户意图、可见性观察和主动跳转分开。
- **保留RetainedContentHost的原生隐藏**；透明隐藏不是停止原生拖放接收的等价方案。保留实例/状态不等于允许隐形页面截获输入。
- 拖放落点说明用途；“松手已接收”不等于材料已就绪。异步结果回原项目/会话/槽位，逐项失败不抹除合法项。移除引用不删除原件。
- 下一次配置、中央旧结果、右侧选择、在途任务四对象分开。切换模态/模式不隐式运行、取消、加载或改变任务。
- 结果抵达不抢走当前候选；保存失败可只重试保存，不自动再推理。排队、执行、取消中、释放完成以实际状态为准。
- 音视频播放策略与生成生命周期独立，现有播放策略先保留；未来更改应明确，不以页面离开取消推理。

## 7. 原型与原生实现的责任

网页原型v0.2是可交互布局参考：玻璃、媒体、生成、语音和节点执行并不全是真实产品实现。音源是预制合成音频，视频为图像运动示意；设置中的路径/网络/凭据布局不修改系统。

原生实现使用现有SwiftUI/AppKit、Runtime/Store、模型能力与图编辑机制，不嵌WebView照搬网页，不复制模拟存储/任务或原型参数作为模型限制。网页未画出的已适配功能保留；模型和后端没有的操作不得虚做。

先完成一版可用原生候选供用户试用，不要求此轮最终审美定稿。现有九模型能力/组件索引已完成，直接复用docs/UI_CAPABILITY_WIRING.zh-CN.md，不再全量盘点。

## 8. 代表验证与当前未定事项

只做受影响代表路径：模态往返/草稿/在途归属；固定媒体视口及窄窗；设置持久化/颜色恢复；节点拖入删除撤销/框选封装/连线/手形导航；长文阅读/搜索/Bottom/输入/实际拖放。复用旧模型和存储证据，不因排版改动重跑全部推理。

原型色号、像素、过渡曲线、会话列表具体展开形式和预览局部排版仍可根据第一版继续改。MIDI与音频中间表示、新模型、更多控制技术、远程功能和免费搜索方案不在本轮。新需求后续讨论不自动授权插入正在执行的任务。

本版是最新设计决定与下一阶段实施边界，当前代码和通过记录仍由仓库唯一行动页/F表维护，不在设计文档持续堆叠回执。
