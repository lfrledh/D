# D 产品与架构指导原则

P2026-09-23.1 · current。来源：2026-09-23 本次产品讨论的用户方向摘要（G1—G8），不是逐字引文；具体UI、注册系统、schema与首发新排期尚未全部设计或批准。

## 当前目标

| 原则 | 当前明确要求 | 不应推导出的承诺 |
| --- | --- | --- |
| G1 统一工作环境 | 面向创作者、艺术家、学生及初学者的本地AI统一节点工作台；模型与程序能力可组合；模态可分类/筛选/承载编辑器，不强制切分工作流 | 文档修改已实现新UI；所有用途各做一套应用 |
| G2 场景是例子 | 短剧、插画、音乐、资料整理用来检验能力是否可复用；用途由组合产生 | 示例自动变成完整DAW、剪辑器或学术系统承诺 |
| G3 分阶段控制意图 | 可准备、检查、修改、选择中间资料，再继续执行；AI建议由用户采用/拒绝，原件保留 | 一句提示替代全部创作；连接或移动节点就自动启动推理 |
| G4 数据可检查 | 节点标明执行来源（模型/程序）、类型、必选/可选输入输出；端口与连接能查状态和内容，必要的专业细节渐进展示 | 创作者必须理解每个张量或任意内部对象；布局就是执行计划 |
| G5 尊重模型差异 | 有意义的专属条件、格式、联合限制和能力等级如实表达；缺能力明确拒绝 | 任意模型兼容、全部Any/字符串参数、新模型永远只改配置 |
| G6 机器不是产品上限 | 模型要求、adapter支持、已测环境、硬件建议、用户选择/准入分开；M4/16GiB只是一个样本 | 取消输入/解析/资源安全预算；静默改精度、尺寸或条件来过测 |
| G7 继承保护 | 原件/恢复/校验/来源/隔离、取消与drain/release、本地失败不自动上传继续有效 | 为赶进度放宽质量、权限或作品安全 |
| G8 整理与产品分开 | S0—S5仅整理事实、规则、导航与可证明退役项；S6只提有限方案 | 本轮已批准并实现节点画布、模型注册表或整体架构重写 |

## 组合与分层不变量

- 数据积木是可版本化、可检查的文本、媒体引用、区域/时间、音符等创作语义；操作声明真实条件与结果，界面提供编辑器/预览/控件。执行依赖与布局分开。
- 项目是保存与恢复边界；文档、资产、运行记录不因切换呈现方式复制或分叉成第二套事实。布局变动不生成任务、不使输入发生隐式转换。异步结果绑定提交时输入版本；过期结果不覆盖已改变的原文/选区/其他文档。
- backend负责模型执行与生命周期，工作台负责组合、人工检查点、候选、采用/拒绝/撤销、保存和来源。下载独立于推理，安装与模型身份不混同。避免每用途重复后端，也不先造空的万能框架。
- 不支持参数显式拒绝；unknown/not_applicable/withheld/invalid不混为默认值。模型控制可精确/近似/不支持；音符不变不代表声音严格服从。实际执行值用于记录，不从后来改变的UI反读。
- 模板/外部元数据只解析不执行；未知版本、大小/深度/数量/解压预算、冲突和缺依赖可见；不自动安装节点、下载文件URI或把资产内容当代理指令。
- 简易入口、专业编辑和未来助手调用共同应用服务；远程API必须明确选择，凭证不进入项目/日志，远程取消不冒充本地drain保证。外部推理服务首次实施再版本化，不以内部Codable当稳定网络API。

## 性能、媒体与发行责任

模型支持内优先最高有效性能，重神经网络GPU优先、CPU可选，NPU只在真实支持及测量后承诺；CPU文件解析不等于模型CPU推理。记录请求/实际设备、精度/量化/回退。流式加载必须验证数值、速度、峰值、取消与完整产物；加载/首步通过不代替全片。详细未决项见[设备政策](EXECUTION_DEVICE_POLICY.zh-CN.md)和[能力证据](MODEL_SUPPORT_AND_RELEASE.zh-CN.md)。

保留RAW/高位深、外部API、手机捕捉等扩展空间，不因此现在实现全部。人类原声→AI转录→人工修谱→渲染分别记录。开发代理来源与用户媒体来源分域；私有/公开导出投影分开，公开提示词不默认泄露。原件不被预览或导出覆盖，发布前回读校验媒体负载/色彩/方向。

正式App不附权重，模型由用户显式选择下载/导入，用户处理自己的使用资格。D负责自身代码/运行时与实际交付和获取行为；保留来源、版本、摘要与适用条款入口，不代接受条款、不给未知权利保证、不建设替用户作法律决定的平台。现有开发产物有内含权重/本机路径等差距，见支持表，不能写成已解决。

原生Mac交互、Liquid Glass导航/控制、准确观察作品的背景、键盘与可访问性要求继续；具体节点画布与布局由用户后续UI方案决定，不能以旧模态按钮实现倒推未来产品。

## 替代关系与权威归属

| 旧指导 | 当前处理 | 保留的事实/责任 |
| --- | --- | --- |
| 固定“项目→主要模态→工作方式” | superseded：G1，统一节点工作方式；模态不是强制入口 | NAV2等旧UI实现及验收仍为historical-fact |
| 节点仅P4研究、默认不需要节点 | superseded：G1/G4为核心方向，具体范围待批准 | 不承诺任意ComfyUI、脚本、循环或插件市场 |
| 全部模态基础完成后才组合 | superseded：按真实依赖重新提案，不再自动续排 | 图文音视频、HUM、歌声、I2V已有首发承诺不自动取消 |
| 小规格实测=产品能力上限 | G6纠正推断，实测范围仍精确保留 | 固定配方/数值/资源保护不随之降低 |
| 审计建议某类/注册表/拆文件 | proposal，需实际问题、反例和验证论证 | 不视为已经冻结的接口或实现许可 |
