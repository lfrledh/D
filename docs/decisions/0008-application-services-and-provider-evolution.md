# ADR 0008：应用服务、模型身份与服务化演进

日期：2026-09-07。状态：用户已批准，D-F03／D-M01 已验收；远程与对外服务仅保留设计约束。

## 当前实施边界

保持单仓、模块化单体、原生 Mac。现有 UI package 内新增承载真实代码的 DWorkbench target，提取项目存储、权限生命周期和任务应用服务；UI target 保留 SwiftUI、原生面板与展示状态。D 应用装配 DRuntime／DMLXBackend。DInference／DRuntime 不依赖工作台、下载、网络或 UI。

| 服务 | 输入 → 输出／所有权 |
| --- | --- |
| 项目会话 | 项目、草稿、提交／取消／导出命令 → 可重读状态与任务结果；拥有任务、保存、恢复和关闭 |
| 模型库 | 安装／校验／定位／移除命令 → 固定模型身份、版本和安装状态；拥有安装任务及使用租约 |
| 执行能力描述 | 当前操作与执行配置 → 实际支持参数和限制；UI 展示与提交验证共享值型描述 |
| 本地执行适配 | 创作条件、模型身份 → 解析且获授权的本地 InferenceRequest；使用现有运行时 |

新公共边界只传 Sendable 值、稳定 ID 与资源引用，不泄露 MLXArray、NSImage、窗口或书签。权限由宿主获取并由服务保持。视图消失或观察者退出不等于取消任务；运行输出由单个任务所有者消费，再提供可重读快照。

不为拆层重写已验收的准入、待保存结果、目录迁移、取消／清理和关闭协调。actor 的 await 仍可重入，保持显式整次操作所有权和回归测试。

## 模型身份与安装

模型身份、固定 revision、安装实例与本机目录是不同概念。选择安装后，提交先取得使用租约，任务释放前不允许移除或迁移其内容。历史记录真实 revision；目录移动不创造新模型。查看已有作品不要求模型存在。

首轮仅固定 FLUX.2 Klein 4B q8。目录登记、完整校验、操作兼容与硬件预算分别表达。安装内容遵循完整审阅清单；暂存、索引与书签不混入后端严格读取的模型树。安装器不通过修改 vendor 或放宽后端校验实现兼容。

下载属于应用操作，不进入推理核心。下载、验证与写盘任务使用有界内存并落在授权模型库；安装失败保留可恢复状态，不发布半成品。外盘不可用明确停止，不回退内盘。安装器不得删除未知文件或外部登记的用户模型。

## 兼容性与版本

界面布局、项目格式、内部 Swift 接口和未来网络协议独立演进。Codable 是序列化能力，不是外部协议的兼容承诺。

- 当前阶段保持项目 v1，不为了服务提取重写旧记录或移动媒体。多文档首次实现时再设计并验证迁移、备份和未知版本处理。
- 当前 UI 与核心共同发布。外部协议在首次独立服务实现时版本化，保留能力查询和兼容测试；不现在冻结未来所有字段。
- 能力描述决定显示和接受哪些操作；后端独立验证。未知操作或不支持参数明确拒绝，不能静默忽略或降为任意字典。
- 现有 ModelReference.directory 是本地运行引用，保留其明确语义。未来远程目标在应用执行层适配，不伪造本地目录。

## 远期扩展的必要约束

**外部 API 进入 D（D-E01）**：应用执行适配声明提供方能力，记录真实提供方、模型、参数和远程任务身份。用户明确选择远程，不能自动把本地失败改为上传。资源取得后校验并持久化为项目资产，不能把会过期的远程 URL 当作已保存作品。凭证不进入项目或日志。首次实现再细化费用确认、幂等提交、断线恢复和凭证存储。

远程“取消已请求”不等于“计算已停止”；超时或观察者断线不代表已失败。远程状态需要可查询并允许待核实结果，不能强行复用本地 execute/drain/release 的停止保证。远程并发限额不占用本地 MLX 许可。

**D 向其他软件提供推理（D-E02）**：独立宿主开放能力查询、提交、状态、取消和产物获取；传输适配与核心分离，不暴露任意文件系统路径。初版服务只面向本机、显式启用并控制调用者访问。服务模式由单个宿主拥有本地 GPU 调度，D UI 作为客户端，避免跨进程各自启动重推理。首次实现再确定网络协议、认证、配额和资源传输细节。

**助手和工作流（D-A01／D-N01）**：操作项目时调用与 UI 相同应用命令；仅推理的无界面调用可直接使用运行时。工作流数据依赖、媒体转换与数学计算图是不同层次。暂不建空 Provider、HTTP Server、RPC、DAG 或插件包。

## 研究依据与验证

[VS Code 语言服务](https://code.visualstudio.com/api/language-extensions/language-server-extension-guide)展示了以协议隔离编辑器与计算工具的方式；借鉴边界，不立即引入独立进程。[ComfyUI 服务路由](https://docs.comfy.org/development/comfyui-server/comms_routes)展示提交校验、队列与状态分离。[fal 异步推理](https://fal.ai/docs/documentation/model-apis/inference/queue)明确运行中取消不保证停止、结果 URL 可能过期；这些语义不能由统一外观掩盖。访问日期：2026-09-07。

本阶段验收用无视图服务调用、旧项目 fixture、模型安装 CPU 故障测试和普通沙盒真实下载／推理分别证明边界。假服务测试不代表外部 API 或 GPU 已兼容；未来目标在目标清单中保持未实现。
