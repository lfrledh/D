# 工作包模板

此文件是填写模板，不是待执行任务。只为近期工作建立实例；Swift 接口与已运行测试是事实来源，不在提示词中复制完整源码。

## 目标与范围

- 编号、名称：
- 用户可观察结果：
- 前置工作包 / 起始提交：
- 允许修改的模块与文件范围（检查实际路径）：
- 本次明确不包含的功能：

## 契约与行为

- 需要阅读的接口、ADR 和调用方：
- 输入、输出和资源所有权：
- 状态转换与必须维持的不变量：
- 错误、取消、超时与清理行为：
- 兼容要求、依赖版本与内存约束：
- 可以自行决定的实现细节：
- 遇到哪些事实应升级为设计问题：

## 验收

- 正常场景及可观察结果：
- 必须覆盖的边界/失败场景：
- 需要实际执行的构建、测试或真实模型实验：
- 完成标准与证据位置：

## 实现交付记录

- 实际变更与设计偏差：
- 运行过的检查、结果及未验证内容：
- 审阅意见与修正：
- 提交与远程分支：

成本观察只记录模型、推理强度、时间和返工等必要信息。账户额度、邮箱、令牌或个人账单不应作为工作包公开内容。
