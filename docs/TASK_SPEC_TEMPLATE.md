# 工作包模板

C2026-09-23.1。仅填写近期任务；Lead维护规格，Worker回传结果不改标准。稳定规则引用[协作规程](MULTI_AGENT_WORKFLOW.zh-CN.md)，关键约束直接写入任务，勿复制全史或逐函数答案。

## 规格（派工前冻结）

- 身份：task_id / spec_revision / batch_id / run_id；产品原则、协作规则与contract_revision。
- 基线：source_base、准备/执行完整SHA、依赖接口/资料版本；实际目录、分支、共同Git目录和索引；准备提交SHA写派工回执而非自引用。
- 目标与非目标：用户/维护者可观察变化；关联目标ID；何时停在阶段边界。
- 范围：逐项允许路径、禁区、共享文件唯一所有者；生产输入/个人修改/候选保护。
- 契约：真实输入/输出类型、单位/时间基/版本、必选/可选/未知值、所有权；正常行为表与关键反例；取消/错误/超时/过期/清理/保存兼容。
- 能力：模型要求、adapter支持、已测环境、硬件建议、用户选择/准入分别列明；UI→请求→实际执行→记录一致，布局不能启动执行。
- 阅读：必须带入的限制与相关失败；必读接口/调用方/资料；按需文档的触发问题；局部实现自由与需要Lead消歧的决定。
- 执行：请求模型/档位及原因、可观察设置核验入口；独立写根、输出/cache/tmp、网络与CPU/GPU/GUI资源；检查副作用预检及唯一预授权安全降级。只读任务也明确禁止写入。
- 验收：冻结正常/边界/失败预期、来源与版本、作者局部检查、Lead独立反例/组合/真实验证、非实现者审阅需求；未测范围。不允许执行者降门槛或换黄金样例。
- 预算：初交/已耗修复/剩余修复/有界接管、时限、停止升级条件；沿用旧任务余额，编号/模型变化不重置。列本批实际并发/重资源排队，不新设全局人数上限。

Worker开始确认修订、基线、目录、允许范围；Lead根据真实设置核验后发实施指令，不能以自述证明身份/权限。变更由Lead明确修订，旧结果不得迟到自动接纳。每轮再派工前先查异常与保护。

## 结果、审核与接纳（同一记录追加）

- 实际差异/补丁或候选SHA；偏差、未覆盖与风险；自有进程状态。
- 命令/方法、环境、受测完整SHA或文件摘要、结果、证据相对索引；通过/失败/跳过/未测分开。
- 每轮实现/修复/审核人；请求与可观察模型/强度及未知；Lead介入类型；权限/环境/规格/代码/集成原因分开。
- 非实现者结论与Lead验收；组合版本、源接纳/推送状态、仅文档最终版本对应关系。最终提交自身SHA放回执/外部证据。
- 观察到的时间/token增量、缓存口径、未知费用，不调查账户隐私或重算旧样本。
- 恢复点：HEAD/索引/个人改动、候选、活跃任务/目录/权限/进程、有效修订、完成/未完成、下一动作及证据；旧规格取消/替代明确。
