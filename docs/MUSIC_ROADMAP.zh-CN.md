# 受控音乐与哼唱路线

2026-09-08，v7 用户需求已采纳；本文为路线和验收出口，非音乐实现授权或本机模型实测。当前只实施 T0/META 有限批次。详细外部研究是提案，不把模型名、研究性能或许可证推测当作已接入事实。架构取舍未定，不生成冻结 ADR。

## 模态推进与有限出口

固定图像范围的生成、取消/释放、保存重开、比较/采用、安全导出已有历史验收，见 EXPLORATION_STAGE_ACCEPTANCE、IMAGE_RUNTIME_ACCEPTANCE。当前签名构建完整 UI 和跨构建授权恢复缺口仍作为相应交付门槛，不阻塞无依赖的文字/音乐数据与 CPU 工作。参考图、蒙版、更多模型、RAW、LoRA、节点是后续增强，不要求先穷尽图像路线。作品丢失、错误参数、取消未释放和不安全导出必须阻塞受影响交付。

文本已有真实本地推理基础（不是 TTS）；T0 接入草稿、选段改写、候选比较、接受/拒绝/撤销、保存重开。先验编辑/版本/取消流程，不预设当前小模型具备专业音乐规划水平。本批只交付可测试编辑服务和草稿 Data 归档，完整生产保存/界面/真实模型闭环待后续验收。不把高级文本功能完成作为音乐前置。

## 创作者所有权与音乐数据

三类对象分别版本化：作品（旋律、和声、歌词、结构、锁定范围）；演奏解释（奏法、力度、微时值、发音）；音频资产（实际声音、上下文/尾音与来源）。时间坐标明确区分原始秒/采样、音符事件和节拍；不暗自把自由节奏量化为固定拍。人类原声→模型转录→人工修谱→模型渲染逐段记来源，不改标为纯 AI 创作。

哼唱另分四层：原声/连续音高、音符事件、节拍/记谱解释、人工修订。录音中断和识别失败不能丢已保存原声。量化/移调/拆合/改拍号均是可撤销解释，不覆盖输入；允许合理多解，用户决定最终记谱。首版不承诺多声部识别、专业全排版或实时神经乐器。验收分别测音高/八度、分裂合并、节奏解释、纠错负担、中断保全，不给未经校准的单一正确率。

锁定音符数据可精确；生成声音服从程度必须分别报告精确/近似/不支持。不能静默将乐谱变成提示词。局部渲染的上下文、尾音和交叉淡化需要明确，不能借边界处理改写已冻结音频。MIDI 事件不等于完整谱面；MusicXML 只接入逐项明确的音高、时值、休止、连音、声部和拍号等子集，未支持输入保留原件并解释限制。

## 候选和验证（未本机通过）

- MRT2 small：器乐候选，官方具音符条件及 Apple Silicon 实现。small 230M 不代表完整运行只占权重大小；codec/style encoder/缓存均计入。官方“快于播放”不等于控制低延迟。资料：[实现](https://github.com/magenta/magenta-realtime)、[模型卡](https://huggingface.co/google/magenta-realtime-2)、[说明](https://magenta.withgoogle.com/magenta-realtime-2)。代码/权重许可分别核验。
- DiffSinger：可控歌声候选，旋律/歌词和表现参数；声库与 vocoder 独立许可。[官方](https://github.com/openvpi/DiffSinger)。
- ACE-Step：补充整段生成/创意伴奏，条件有近似性，不替代严格乐谱通路。[条件边界](https://github.com/ace-step/ACE-Step-1.5/blob/main/docs/en/Tutorial.md)。MIDI-SAG 保留伴奏研究，依赖链较长，[官方](https://github.com/fundwotsai2001/MIDI-SAG)。
- Basic Pitch 为录后音符候选，[官方](https://github.com/spotify/basic-pitch)。SwiftF0 为单音基频候选，需要分音/记谱；名称不证明原生 Swift 兼容，[官方](https://github.com/lars76/swift-f0)。NeuralNote 仅工程参考，处理速度不代替端到端延迟。本轮未选择、安装或实测这些依赖。

M4/16 GiB、外盘、小片段、离线先行，单重推理任务。分别测冷启动/首音、控制延迟、吞吐、峰值内存和取消释放；播放/UI 不在模型计算线程等待。现有文字/图像精度不改；音乐模型和量化显式确定。源码/模型/声库/vocoder/输入素材逐项核验，不假定闭源可嵌入、不要求云服务。新依赖、权重、费用、权限和声音质量承诺另行授权。
