## 已确认成本、反证与取舍

1. **焦点轮廓**：`da6f51759fc4039af5bda466e13aa9a6afc34f4a` 引入工作区focusable。当前30.80757s Time Profiler+Animation Hitches记录中，主线程6392个Running样本，AutomaticFocusRing、drawnFocusRingBitmap、CGSRegionFromBitmap相关焦点位图调用链并集967ms（15.1%），整工作区内容参与焦点轮廓位图计算。单一焦点形状对照的25.761026s CPU采样未再采到该链；与侧栏跨轮次/编译设置改善相符。不同采样窗口不能用总CPU相减。仅明确focusEffect形状，不关闭键盘焦点、不整页栅格化、不删子控件焦点。
2. **重复查找**：焦点修后采样中语言text链631ms、解析537ms，功能线性查找179ms；语言text包含解析成本，不能重复相加；179ms为独立静态定义查找子链，与text交集为0，不能与会本地化的purpose混用。本次缓存仅语言选择解析（每次仍追踪可观察selection/revision），功能索引仅静态127项，同一body帮助文字取一次。代表采样中语言1ms、功能链0样本，不等于从未调用；低干扰PAN/ZOOM未证明额外显著收益。
3. **拒绝的材质/宿主改动**：把官方玻璃搬到独立底板，保持几何内容，PAN22.762→33.274、ZOOM99.955→181.146ms，未采纳。去掉根背景显式wantsLayer但保留继承层也无改善：固定ZOOM178.448ms、侧栏309.595ms，未采纳。背景draw计数在固定两组均无新增；保留标题栏strip、菜单兄弟层、画布opaque和前景保护。另一1900×1030组及首次NODE目标不同均不当严格重复。
4. **运行投影**：代表采样25.76412s/PID21410，1174主线程Running样本，工作区投影6ms、完整运行值身份2ms、保留宿主更新1ms；不支持继续盲改摘要/历史缓存。采样开始约14秒后才派发NODE/PAN且无可靠输入时钟联结，只解释被采到的路径；不能声称全手势覆盖或与上一总CPU直接比较。剩余AG更新、hover/命中和tracking相互重叠，未确定新的因果修补。
5. **缩放尺寸**：尺寸回写在6f5前已存在，onGeometryChange已有Equatable比较。新菜单固定点留白可造成真实归一高度变化，不能用宽容差/冻结几何掩盖。最后仅将卡片菜单固定外留白移到随字号缩放的label内：同-O两次ZOOM p95为100.574/99.867ms，相对正式106.067仅约5—6%，且改变非1x外观。无可靠呈现/几何反馈因果证据，未采纳；正式包不含此实验。两轮160事件及缩放复归均完整，复制夹具session错误的启动前0事件失败另保留。
