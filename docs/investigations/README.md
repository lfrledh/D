## 归档约定

- 每项调查使用 `docs/investigations/<TASK-ID>/`，以 `README.md` 为该项入口；没有既有任务ID时使用日期加主题的目录名。同一调查追加日期/版本说明，不为每次反馈另造常驻入口。
- 记录实际对象完整SHA、目的和访问范围、方法/条件、当前实测、源码推断、历史沿用、支持证据、反证、未知项与审阅状态。报告不自动授权产品修改或实施下一阶段。
- Git只放去敏报告、必要的小型数据摘要和证据索引。原始trace、日志、用户内容、索引、书签、凭据与私人路径留在受控本地；用逻辑证据集标识及相对文件名关联，不能把它们作为附件整包上传。
- 经当前任务明确授权，可同时收录纯离线分析器、合成测试、去敏衍生表及方法验证回执，支持复算。诊断产品源码/插桩、构建产物和原始私有证据仍留本地，不能混入产品交付。
- 实施任务、代码修补及测试规程仍沿用原任务文档。当前授权/候选仍以[当前行动](../CURRENT_ACTIONS.zh-CN.md)为准；真正需要人类的事项与环境阻塞分别记入[集中待办](../FAILURE_AND_PERMISSION_AUDIT.zh-CN.md)，本目录不复制全项目当前状态。
- 新调查登记到上表；更新报告保留时间和版本边界，不覆盖原失败、未验或历史结论。需推送的范围依用户当前授权，不因归档约定自动推送私有证据或代码。
