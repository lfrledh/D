# D 产品目标清单

更新：2026-09-07。这是当前产品目标、顺序与验收状态的统一入口。历史计划用于理解来源；阶段报告保存当时的事实，不被新目标覆盖。

D 面向专业 AI 创作者，兼顾初学者：在自己的 Mac 上安装模型、组织创作、运行推理和保存作品。易用模式、专业参数和未来节点工作流共用请求与任务服务。产品完成度建立在文件安全、可信的任务状态、可恢复的作品及原生 Mac 体验上。

## 如何追加和维护目标

- 每个目标保留稳定 ID；讨论中新增目标先记录用户价值、优先级、依赖和验收终点。
- 状态使用「已验收」「实施中」「已接受／待排期」「研究中」「后置」。新增目标不会自动扩大当前检查点。
- 每次检查点更新对应状态、实际证据和剩余限制。构建、模拟测试、真实推理及 UI 实测分别记录；没有运行的验证不能标为通过。
- 如果新目标要求改变正在实现的边界，先写出影响与取舍。只提前保留有依据的数据边界，不预建空插件、解码器或未来框架。
- 本轮 **D-W01 图像项目工作台** 已验收；下一检查点为 D-M01，模型安装器和其他后续目标需单独细化交互与验收。

## 当前就保留的媒体与项目边界

1. 作品以稳定资产 ID、相对文件引用和来源记录为事实；`NSImage` 只是显示对象。
2. 项目区分原始媒体、派生结果、预览和缩略图。未来导入的原件保存在自包含项目中；共享模型权重始终留在项目外。预览可重建，不覆盖原件。
3. 媒体服务在工作台层负责解码、缩略图和导出；推理后端负责模型需要的预处理。像素数组和 MLX 内部类型不进入核心接口。
4. 元数据记录能够确认的格式、尺寸、位深、色彩空间等；未知值保持未知。当前 PNG 支持不代表所有未来媒体都是 sRGB／8 位，也不代表已实现 RAW 解码。
5. 项目格式具有版本号和迁移入口；相对路径使已保存作品随项目移动。恢复仅检查该项目已记录的任务所拥有的目录，不扫描或删除用户其他文件。
