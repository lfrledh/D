# D 整体产品规划：以可控的视觉创作为核心

确认日期：2026-09-07。状态：用户已确认；具体能力以目标清单和验收记录为准。本文件保存长期方向，不自动授权实施全部远期目标。

## 定位与边界

D 是面向创作者的 Mac AI 创作工作台，帮助用户把想法变成作品，并通过参考、修改、比较和整理持续掌握创作方向。它能独立完成关键创作流程，也能把成果顺畅交给其他专业软件。

首批聚焦视觉探索与创作：插画、角色、海报视觉素材和静态分镜；面向专业创作者及学习这些工作的学生。用户选择了「独立创作并顺畅协作」，不要求替代 Photoshop、排版软件、剪辑器或音频工作站。

先完成一条有实际创作价值的完整流程，再沿相邻场景扩展模态；不先铺齐全部推理核心，也不等待图像领域的所有功能完成。「生成成功」是技术完成；「可以把结果修改到可用、恢复工作并交付」才是产品完成。

角色创作的代表流程：整理描述与服装配色参考 → 探索候选 → 选定方向 → 保留满意部分并修改其他部分 → 比较与分支 → 导出协作 → 几天后继续。现有推理、任务、安装及保存基础继续复用，不因战略调整重写已验收核心。

| [Fusion](https://www.blackmagicdesign.com/products/davinciresolve/fusion) | 节点表达复杂效果关系，也可封装宏暴露少量参数供 Edit 使用 | 制作工具与使用工具可以分层；节点有专业价值，但不是默认创作语言 |
| [Krita 色彩工作流](https://docs.krita.org/en/general_concepts/colors/color_managed_workflow.html) | 区分输入、工作、显示与输出的色彩职责 | 格式支持不仅是能解码，还包括颜色、位深及交付 |

| [界面与创意探索研究](https://arxiv.org/html/2312.00233v2) | 快速变体交互与较少的新概念探索相关 | 简化不能只鼓励重复抽样；观察性关联不证明因果关系 |

节点从必经阶段改为条件研究。交互依次提供直接操作、按需展开的专业控制、预设及重复操作；真实组合需求出现后再判断步骤编辑器或节点图。简单与专业共用创作状态及执行路径，不以技术参数数量定义专业性。

## 功能版图

分类是产品职责，不强制对应页面或独立代码库。「基础」是持续门槛；「核心」构成首批完整价值；「扩展」按需求进入；「研究」尚非实现承诺。

| 类别 | 用户场景与具体能力 | 级别／主要难点 |
| --- | --- | --- |
| 构思与参考 | 创作说明、图片与备注、配色构图参考；区分观察参考和模型条件 | 核心；避免复杂项目管理或强制 AI 处理每条信息 |
| 视觉探索 | 文生图、参考引导、候选生成、收藏淘汰、从方案继续 | 核心；重视候选可用性而非数量 |
| 定向修改 | 选区/遮罩、局部重绘、扩图、对象替换、保留原件、采用或放弃修改 | 核心／高；模型与合成都须验证，不用整图重生成冒充局部编辑 |
| 精修与素材 | 裁切缩放、透明背景、抠图、必要基础调整；按需放大与细节修复 | 基础处理核心，高级修复扩展；不建完整绘画引擎 |
| 比较与版本 | 并排和同位置比较、命名、备注、分支、明确采用版 | 核心／跨模块；任务记录不等于作品版本 |
| 系列创作 | 共享参考及约束、系列候选、角色/风格连续性辅助 | 扩展／高；不承诺绝对一致 |
| 叙事与分镜 | 镜头卡片、顺序、对白/动作备注、参考复用、分镜表导出 | 相邻扩展；静态先于动态预演 |
| 交付与协作 | 可靠导出、尺寸颜色透明度、批量命名、联系表；按需分层交换及外部结果回收 | 核心到扩展；完整 PSD 往返非默认承诺 |
| 项目与资产 | 自动保存恢复、来源引用、集合搜索、归档、适时多文档 | 基础；原件、预览、候选、采用作品归属清楚 |
| 重复劳动 | 预设、重复操作、受控批量、任务优先级；按需组合步骤 | 扩展；先有重复工作，再有编程平台 |
| 学习与理解 | 示例、就地解释、实际参数、单因素比较、过程说明 | 引导核心，其余扩展；不做课程平台 |
| 文字辅助 | 创作说明、提示词建议、分镜文字、局部改写和多语言辅助 | 相邻扩展；可预览拒绝，不悄悄改变意图 |
| 声音与动态 | 临时旁白、转写、音效候选、镜头动态预演，按需生成音视频 | 扩展／高；不同时做完整剪辑器和音频工作站 |
| 专业媒体 | RAW/DNG、高位深 TIFF、OpenEXR、专业音视频容器与编码 | 扩展／高；原件、解码、色彩与推理分别验收 |
| 运行与资源 | 安装校验、硬件预算、存储、取消恢复、可信进度与诊断 | 基础；已安装不等于操作兼容或预算可用 |
| 外部能力 | 可选在线生成、费用和上传范围；后续本机服务/软件集成 | 扩展；明确选择执行位置，不静默上传 |
| 商品化 | 原生 Mac、Liquid Glass、键盘/辅助功能、迁移升级、签名发布和帮助 | 基础体验持续验收，视觉精修迭代 |

定向修改、候选比较、版本关系、参考组织和交付协作都是产品核心，不笼统归为外围功能。成图、可恢复的创作文件、实际生成记录分别保存；有生成记录不代表跨模型升级或后端变化仍逐像素复现。

## 模态与范围管理

| 方向 | 角色与启动条件 |
| --- | --- |
| 图像 | 先完成有限操作的探索、修改、交付；不追求所有模型 |
| 文字 | 复用已有核心支持创作说明及分镜，先验证辅助质量，不恢复通用聊天产品 |
| 图像理解 | 只有确实减少参考整理负担才接入；识别结果可纠正，不自动视为事实 |
| 语音/音效 | 由分镜、教学演示、动态预演等需求触发，逐项接入 |
| 视频 | 动态探索；质量、等待、内存、保存及连续性满足目标任务才进入 |
| 三维 | 概念资产与空间创作的条件研究，尚无承诺 |

新模态进入产品前必须回答：帮助谁完成什么工作、当前交接为何不够、共享与专属能力分别是什么、目标硬件上完整流程是否可接受。关键疑问可做有停止条件的实验；实验成功不自动产品立项。M4/16 GiB 是初始验收配置，继续外盘优先和单重任务；容量不等于运行内存。

更多模型/LoRA 由缺失的创作操作驱动；局部文字辅助与自主项目助手分开；多文档由真实探索组织驱动；RAW 后置，但原件安全、基本色彩和透明度不后置。完整绘画、专业排版、完整剪辑/音频工作站、通用聊天、社交社区和实时多人协作排除当前承诺。训练、插件市场、任意 ComfyUI 工作流兼容保持未承诺研究。

## 长期结构与 API 边界

项目拥有创作内容（说明/参考、编辑状态、候选/版本）、素材/采用作品及生成记录；模型和预设为共享资源。模态用于操作与筛选，模型用于执行，不要求先访问模型目录才能开始创作。

工作台、任务管理、后端保持分离。稳定 ID 与值型操作供 UI、未来助手、外部入口共享，不暴露 MLX 数组或硬塞成 token/无类型字典。项目格式、内部 Swift API、外部协议分别演进。图像选区坐标与音视频时间、声道、帧率保留专属语义；不为未来建空框架。

本地和远程共用创作对象，分别表达取消、费用、隐私、恢复；已保存作品不依赖过期链接。本地失败不得静默变为远程上传。Liquid Glass 用于导航/控制，画布保持中性不透明背景。
