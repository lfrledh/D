| 情况 | 冻结行为 |
| --- | --- |
| 移动/缩放/折叠 | 仅布局，不修改配置revision、不加载或推理 |
| 新输入/改参数 | 新revision；旧结果保留并标旧输入，不自动执行下游 |
| 运行到这里 | 提交前显示执行/复用/等待；固定图和资产版本；人工等待停住并保存 |
| 重跑本步 | 仅用已就绪上游快照；不重算确认文字；新增attempt，旧结果保留 |
| 已连接可选口未就绪 | 明确阻塞，不当成未提供；集合不能自动取第一项 |
| 确认/采用 | 绑定具体waiting run及输入版本；重复确认幂等，预览/高亮不算采用 |
| 三候选部分失败 | 成功资产保留；失败项独立重试；部分集合需明确确认 |
| 保存失败 | 原作品和旧权威pointer不变；保留完成结果供保存重试，不自动重新推理 |
| 继续会话/改文稿 | 不改已发布资产版本，不自动运行图；画布文字可显式回文稿 |
