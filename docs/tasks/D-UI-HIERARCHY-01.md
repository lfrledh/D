## 2. 固定的信息层级

```text
D
├─ 项目选择（普通启动首页）
│  ├─ 新建项目 / 打开项目
│  └─ 最近项目（只展示已记录项目，不扫描磁盘）
└─ 当前项目：名称 + 返回项目选择
   ├─ 顶部模态栏：图像 | 文字 | 音频
   │  └─ 当前模态的工作区
   │     ├─ 创作列表：本模态的多份工作 → 当前编辑区
   │     │  ├─ 当前输入、画布/正文/声音预览
   │     │  ├─ 当前创作的候选 → 比较 / 采用或拒绝
   │     │  └─ 当前操作参数 → 兼容模型 / 高级参数
   │     └─ 资产面板：本项目资源，默认仅本模态
   │        └─ “也显示其他模态” → 只读预览 / 明确后续动作
   └─ 项目任务入口：各模态运行状态，保留来源

应用菜单：模型库、设置。它们是共享资源/应用配置，不与模态并排。
```

没有作品的已支持模态显示“新建图像创作／新建文稿／新建声音创作”，切过去不自动创建文档或写入空任务。未来视频、歌声、哼唱识别只有可用工作流落地后才出现对应入口；不先填一排灰色占位。音频栏是本轮设计目标，真实发布时受AW1产品验收门槛控制，不能仅因CLI可生成就默认启用。

## 3. 默认摆放

|位置|放什么|明确排除|
|---|---|---|
|项目顶栏|返回项目、项目名、项目任务状态|当前模型的大标题、跨模态混用的生成/导出按钮|
|其下独立模态栏|图像、文字、音频；可见选中状态|“模型”“设置”“全部作品”这种不同层级标签|
|左侧区域|“创作／资产”两种面板切换；创作只列本模态文档，资产提供简单筛选|候选、全部文档、项目列表全部挤在一个长列表|
|中央|当前文档编辑器；标题/保存状态；局部编辑、比较、导出动作|因查看外模态资产而自动替换当前编辑器|
|中央下方|当前文档候选；文字原文/改写、图片候选、声音候选，按模态呈现|所有项目资产混成候选；资产预览自动采用|
|右侧可收起参数区|当前操作的提示、参考、参数、兼容模型、主操作；少用参数折叠|让文字出现图片尺寸；让图像出现音频区间；只剩一个选项仍显示选择器|

“创作／资产”是同一模态内的面板入口，不是更换项目。参数始终跟随当前创作，资产详情在资产面板内预览。用户从模型选择进入的列表先筛兼容模型，管理/安装进入现有共享模型库；不复制三份模型库。

Liquid Glass采用Apple原生导航、工具栏、按钮材质；画布、正文、波形及资产内容保持清晰、中性。避免玻璃叠玻璃，降低透明度/减少动态/提高对比度后层级仍可辨认。依据：[Apple Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)导航与内容分层、可访问性部分（2026-09-11核对）。HTML草图表达摆放与切换，不证明原生材质的最终效果。

窄窗口先收起参数区为可打开的面板，再折叠左侧列表；主要编辑区、模态和回项目入口始终可达。工具栏按可用宽度重排/收纳，不靠窗口边缘裁切。实现阶段保留已验证最小窗口860×580作为第一组基线，另测1024和1440宽度；具体阈值由真实控件测量决定，不机械照抄草图。草图360px适配只是会话内预览，不承诺手机产品。

## 4. 资产的最小规则

1. 范围永远限定当前项目。默认“本模态”，勾选“也显示其他模态”扩展为本项目全部资源；切换模态重置为本模态。每行显示名称与类型，计数反映过滤后集合。
2. 过滤/预览不调用showAllArtworks、revealAsset或采用操作，不改变activeDocumentID、主画布选中候选、生成参考或模型。跨模态预览也不自动开启生成或触发转换。
3. “打开来源创作”仅在来源文档确实存在且对应编辑器可用时出现；无来源或能力不足仅显示可用预览及明确原因。“用作参考”必须由当前操作的能力和格式校验决定，不按文件后缀推断。
4. 媒体按已记录且可识别的mediaType分类，未知类型保留“其他/未知”，在全部范围可见。不通过所在文档的模态误判附件类型。
5. 已保存文字文稿可用标为“文稿”的文档引用行投影到文字资源列表；它仍是文档记录，不伪装成文件型ProjectAsset、不编造路径/摘要。素材文件与可编辑文档使用不同ID种类，打开和导出分别校验能力。此为少量展示适配，不增加持久化资产平台。
6. 本轮不做复杂搜索、标签体系、集合、跨项目素材库、媒体转换或批量整理。原始资产与导出快照仍按既有规则保存；过滤不迁移、不复制、不删除任何媒体。

## 5. 切换与保存行为表

|事件|规定行为及反例|
|---|---|
|普通启动|显示项目选择，保留最近记录；不自动打开上次项目、不因显示列表读取全部项目内容。最近项仅来自成功打开/保存过的项目，名称缓存和授权记录沿用受控存储；缺盘可见，不静默删记录。|
|用户明确从Finder打开项目|作为明确的打开动作可直接进入该项目；不是普通冷启动自动恢复。重复打开同一项目不重建会话。|
|选择模态/文档|先通过现有保存及离开门槛，成功后一起切换可见模态、文档和编辑器。保存失败保持原界面；不能“标签已是音频、正文还是文字”。|
|文字生成或候选未处理|保留现有拒绝离开的门槛，提示先取消/接受/拒绝等明确动作；不默默丢弃、接受或承诺目前尚未实现的后台候选跨控制器保存。|
|图像/音频生成中切换|仅在原服务允许的安全边界导航；任务条件和来源冻结，结果回原文档，不抢当前焦点。切换不是取消；取消仍由明确操作触发，释放完成才结束。|
|切回已访问模态|恢复本项目该模态最近有效文档；ID无效时选择现存文档或空态。会话内导航偏好与项目内容分离，不为导航新增一次媒体迁移。当前单activeDocumentID仍由服务拥有；不再造一份并行权威状态。|
|资产预览/过滤|编辑器/选区/候选不变；关闭预览回原现场。选择外模态文件不等于能送进当前模型。|
|A→B→A或迟到文件面板结果|用项目/文档/导航代次检查操作归属，单纯比较当前UUID不足。失效操作拒绝，不写回新工作现场。|
|返回项目选择/换项目|走现有保存、取消确认及drain门槛；未完成不能先拆掉编辑器。数据/资源处理通过后才进入项目选择。|
|快捷键与菜单|与可见模态/文档的同一命令状态绑定；不能顶部为音频而⌘Return仍生成图片。文件面板/项目切换期间沿用禁用保护。|

不在这次导航设计中修改推理精度、模型参数真实性、文本Unicode选区或候选采用语义。旧启动自动恢复测试因新用户需求需要明确更新；项目安全恢复、冲突保护和输入法测试不因此删除或降低。
