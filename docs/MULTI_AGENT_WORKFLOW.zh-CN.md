# D 常规协作规程

2026-09-08，v7 授权；状态：常规多子代理开发流程已启用；D-T0-META-01的双执行/审核/组合验收/本地接纳证据已齐。本规程的异常分级从本次记录开始生效，不追溯改变 RESULT-01 历史违规。产品目标见 PRODUCT_STRATEGY，任务就绪与证据见 CURRENT_ACTIONS 和 docs/tasks。

## 分工、任务和基线

唯一 Lead 负责产品取舍、接口、共享文件、任务规格、资源、验收和集成；按就绪度用 0—2 个子执行／评审任务，禁止递归。Worker 只实现有版本且明确允许文件的任务，不改任务单、契约、验收标准、其他任务或源分支。Reviewer 是非实现者只读审核，不能把证据读取称为独立执行测试。Lead 重要实现另由非实现者检查。首批已通过，默认按就绪度使用0—2 Worker；不强行并行，也不自动扩大产品授权。

每批 Lead 有专属集成工作树，Worker 从同一准备 SHA 各有独立物理工作树／分支／索引。使用已验证独立 CLI，显式 model/effort、workspace-write、网络关闭、仅本工作树及本 run 输出／tmp 写根。共享 Git 管理目录不授予 Worker；Worker 交回后由 Lead 显式暂存提交。目录隔离、可见沙箱和实际模型路由分别核验，不能仅凭子代理自述。

任务单含 task_id/spec_revision/batch_id/source_base/base_sha/contract_revision/run_id、目标非目标、允许文件／禁区、输入输出和错误、资料索引与关键反例、请求模型档位、目录和资源、输出缓存临时目录、验收及剩余修复预算。准备提交 SHA 在派工 request 记录，避免自引用提交。Worker 预检确认 Git 身份和契约，Lead 核验实际 turn_context 再发 IMPLEMENT；同一运行链路变化须重核。

## 副作用和停止

任务预先声明正常输出、缓存、临时目录。Python 源码用 tokenize.open + compile(source, filename, 'exec', dont_inherit=True) 仅内存编译；不执行目标、不用默认 py_compile。行为测试另做；其他进程缓存不能因此声称消失。

预先写入任务手册的确定性降级，仅限唯一已授权缓存／无字节码入口，且未成功越界、未扩大权限、无未知副作用时，记录并恢复一次。没有预先允许的权限拒绝先暂停该动作并报告 Lead；Lead 可在原授权内判断，不自动交用户。成功越界、提权、错误仓库、输入损坏、敏感访问、非授权网络或不明副作用立即停止相关写入。预期受控拒绝夹具不算权限事故。Lead 每轮返工前先查异常和保护证据，再看通过数量。

普通新任务初交＋最多两次针对性修复；用完可一次有界 Lead 接管，仍失败停止，不换编号重置。RESULT 旧预算单独保留。每次执行限 15 分钟，只有 Lead 处置自己持有的子进程句柄；进程枚举不可用不提权。取消／规格替代明确记录，迟到结果不自动接纳。任务阻塞不冻结无依赖工作，隔离／数据事件暂停受影响写入。

## 审核、整合和资源

Worker 停写后回传实际文件、证据、偏差、进程和候选。Lead 串行审核提交固定 SHA，再在隔离集成树保留历史合并；语义明确的局部冲突由 Lead 处理，接口／签名／数据风险或未知来源暂停。不 rebase/cherry-pick/squash/amend/reset/restore/stash/清理。每加入任务做相关检查，最终组合 SHA 按冻结验收验证。源快照变化若可对应获准任务，先在隔离树同步重验；未知变化暂停。源只快进接纳已验收组合，前后核对用户 scheme 内容／摘要／索引／未暂存状态，不使用 git add -A。

重构建串行并用独立 scratch/DerivedData。Worker 只做局部 CPU 检查，网络关闭；如 SwiftPM 内层沙箱受阻，报告 Lead，不自行禁用或扩大权限。Lead 可在工具审批的限定命令上运行原沙箱内离线构建，不能改全局配置。真实文字推理和 GUI 仅 Lead 能核实资源隔离／原有授权时执行，不关闭用户 D。无法执行则分别报告组件 CPU、装配编译和真实产品闭环；未验收路径不默认接管已有行为。

## 来源与恢复

task/run 关联规格、请求／实际可观察模型和档位、每轮实现／修复／审核者、候选、受测与集成版本。隐藏服务解析 unknown。Lead 帮助区分澄清、反例、解法与直接改写；保留 squash 等历史来源但本批不用这些操作。不改人类 Git 作者、不逐函数标签。开发 Agent 来源与媒体生成来源是两个域。

用量仅核对增量；缓存属于输入时不重复相加。墙钟、token、完整 Lead 归因、订阅费用分别记录，未知留 unknown，不重算旧样本。少量样本不证明模型普遍能力或最优成本。

持久证据在外盘 D-Development/AgentTrials/<task>/<run>，小规格／摘要入 Git，大日志和产物不默认入 Git，不只放工作树。恢复时核对 HEAD／索引／个人差异、活跃任务身份／目录／权限／进程、有效修订、已完成／待完成、下一动作与证据，不能只信聊天摘要。AGENTS 只留不变量和按需索引。待首组双方真实执行有时间重叠、独立审核、组合验收及源接纳全部成立，再将默认状态改为按就绪度 0—2 Worker；不等于 T0、音乐或整个产品完成。

首批结案证据：[D-T0-META-01](tasks/D-T0-META-01.md)。执行时间重叠229.3338秒，双方生产代码由Terra实现、Lead非实现者复核；META测试夹具一次Lead有界收尾单独归因。每轮原预算不刷新。桌面原生自动派工与隐藏服务解析仍未知。

## v8 增量：按有限里程碑执行与验证通道

用户可以一次批准有终点的产品里程碑，Lead在既有边界自行准备契约、选择0—2 Worker、澄清、有限返工、审核、隔离合并和验收后本地接纳；不为这些普通动作逐项请示。批次目标/非目标、工作包依赖、最多在制范围、剩余预算和检查点写现有任务记录。没有就绪任务不凑并行；一个任务阻塞不冻结安全且独立的工作，第二独立闭环也阻塞时停止扩大。授权不改实际工具沙箱，不授权新依赖/模型下载、费用、权限、真实作品迁移或发布。

验证通道分开核对：固定源码及产物签名/entitlements；明确产物路径和可观察实例；当前GUI/GPU窗口和独立项目/偏好。发批次指令不是空闲确认。仅库存查询响应不等于可控制目标应用；同bundle ID不等于容器隔离。复用D_UI_TEST_SESSION UUID入口，避免恢复真实最近项目，明确禁止操作原D；需用户提供窗口时集中询问一次，未答复不运行真实GUI/GPU。GUI查询用短有界入口；只在有明确修正时重试一次，不能另一工具绕过相同访问限制。

普通签名测试构建可在用户本轮授权和技术许可内使用原本机配置，完整独立DerivedData/依赖副本/产物，不变更身份、Team、entitlements或钥匙串策略。禁止签名构建只证明编译。记录Xcode可能自动登记LaunchServices，不能宣称系统零变化，后续不按名称猜测应用。保留原生SwiftPM构建沙箱，不叠加相冲突的包装；固定依赖、禁更新和Git协议设置仅是对应工具的网络控制，不等于系统强制断网。出现新许可/无法隔离时停止该步骤并给具体动作。

确定失败保留证据、判断根因和预算再修；尚未解释的偶发失败即使随后通过也保留unknown。非实现者审阅和实际测试分开；修复预算用完或有界接管未达到冻结门槛，不靠新编号/改名/换模型增加额度。重要Lead实现与新增风险须由非实现者检查。受测SHA、只文档最终SHA、原件保护、子进程结束状态和下一动作都进持久回执；未真实验收的新路径不默认替代已有行为。里程碑结束或明确阻塞即停止，不承诺未来后台执行，不自行启动下一产品批次。
