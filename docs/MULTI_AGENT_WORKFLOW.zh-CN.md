# D 常规协作规程

C2026-09-23.1 · current。适用后续新规格；历史失败、授权、验收与剩余预算不追溯改写。产品方向见[原则](PRODUCT_PRINCIPLES.zh-CN.md)，唯一当前任务/候选入口见[当前行动](CURRENT_ACTIONS.zh-CN.md)。复用已验协作机制，不为新任务重做切换试验。

## 角色与就绪

Lead唯一协调产品取舍、契约、规格、共享文件、资源、验收和集成。Worker只实现有版本、允许文件明确的局部任务，不改授权/规格/通过标准/其他任务/源分支；Reviewer先独立检查明确候选和需求，再读实现者解释。重要Lead实现需非实现者检查；审阅旧证据不等于独立运行测试。

项目无固定人数上限，按任务独立性、真实工具并发额度、内存/缓存、风险与审核吞吐选择，禁止递归。无就绪任务就用零Worker；不为并行制造抽象、外围脚本或互等任务。普通低风险文档可以一次批量处理。

先降低决策歧义，再分配模型：任务包直接带关键限制、输入输出、状态/所有权、单位/版本、正常与反例、独立验收、允许路径及局部选择权；不要全史、逐函数答案或一句“遵守全部文档”。共享接口未就绪先由Lead澄清。历史Astra/Sol/Terra/Luna分配只是经验，不是模型能力保证；按本次可用ID/档位和可观察运行上下文核验，不凭自述或旧配置。

## 隔离与授权

每批Lead独立集成工作树；写Worker从固定准备SHA有独立物理工作树/分支/索引及受限写根。沿用已验证独立CLI链路，显式请求模型/effort、workspace-write、网络关闭、仅任务树及本run输出/tmp/cache可写。共享Git管理目录不授写权；停写交回后由Lead显式暂存提交。请求、实际可观察设置、服务端不可见解析分开记，后者unknown。

预检确认真实目录、Git共同目录、HEAD、规格、允许路径和禁区，Lead核验实际运行权限后才发IMPLEMENT；换链路/模型/权限后重核。继承全访问不等于隔离通过。只读调查可共享固定快照，但不能用它代替写隔离。独立会话不自动共享历史，文档状态变化不是自动触发器。

已批准阶段内普通派工、澄清、有限修复、审核、工作分支提交/推送不逐项请示；下一产品阶段须批准。长期开发材料授权覆盖获准阶段必要固定版本下载及外盘独立环境，Lead核对来源/许可/摘要/空间；是否需要下载按当前获准任务判断。新费用、外部消息/服务、下节以外的权限扩大、真实用户迁移风险、质量承诺改变、正式发行、许可证/商业变更或超预算重写集中交用户。不把曾批准的一封限定询问推广为任意外联。

## 持续开发验收授权与受阻处理

2026-10-27用户明确批准：完成D既定开发、排错与验收所需的操作持续有效，直到用户撤销或修改，不随轮次、会话或上下文压缩失效。本节替代旧“仅本轮CGEvent”、逐PID申请已知测试实例恢复及反复询问Mac空闲的门禁；旧请求和失败保留为历史，不能继续显示为当前请求。授权不扩大产品任务范围。

Mac默认交Lead使用；用户说明用机时立即停止输入、释放自己按下的键/鼠标，在安全点让出桌面和重负载。Lead串行协调GUI、构建、推理与采样，其他Agent不同时操作桌面。操作前核对当前包/源码、PID和启动时间、窗口/坐标、专属项目及未保存状态；不以旧PID、同名App或旧回执替代。

| 持续获准的工作 | 边界 |
| --- | --- |
| 原生键鼠、AX、CGEvent移动/点击/长按/拖动/滚轮、快捷键，测试窗口尺寸/全屏 | 按工具政策使用已授权通道；只操作准确测试对象，不改产品命中/焦点来迎合工具 |
| 截图、短录屏、只读采样、定向调试/Instruments | 只取D及受控测试内容；无关私人内容/凭据不入证据，不做长期输入监控，诊断开销与正常包分开 |
| 辅助功能、屏幕捕获、自动化等开发验收必需访问 | 用户操作意愿已授权，只走实际所需合法申请；系统/工具强制本人批准仍由本人完成，不预先开启全部权限，不给发行D加测试特权 |
| 专属项目、typed record/opaque、媒体/模型夹具，可逆保存/空间/访问故障 | 隔离、记录前值并恢复；可用临时磁盘映像，不拔用户盘、不撤真实模型目录权限、不写用户项目 |
| 固定版本模型/依赖取得、登记、推理回归 | 复用已有资源；核来源/摘要/空间，不代第三方授予权利，不索要聊天中的凭据 |
| 保存、正常退出、冷开、候选切换、已知测试实例恢复 | 保护用户内容，具体恢复门槛如下；退出后只用不会启动App的识别方法核对PID消失 |
| 旧测试产物清理、修补/定向测试/复核、本地签名/Archive、工作分支提交推送 | 清理准确清单中已停用可重建项；保留当前候选、用户原件/模型、失败与对照证据；不自动合并main、上传或发布 |

已知专属测试实例卡死时，先尝试正常Quit，辨认保存确认、活动写入及真实等待阶段，保留短采样与落盘证据。只有当前PID/启动时间/执行路径/Bundle和专属数据归属均吻合，且已验证保存或明确为可丢弃夹具、不影响用户数据/模型原件/其他项目时，才能定向终止该测试进程及准确归属后代，无需每PID重复请求。未知内存内容可能属于用户时保留实例并隔离继续。记录“受控终止恢复”，冷开核对，再单独验正常退出；强退不算正常Quit通过。禁止killall、清全局剪贴板、重启系统服务/机器、撤保存门禁或改安全策略掩盖缺陷。

同一失败、同一参数且无新依据时停止重复；有明确修正才做一次定向验证，仍失败改用已授权且工具允许的替代路径或收窄阻塞。不得把捕获错误自动称锁屏/权限不足，不把夹具缺失、窗口未激活或输入未到达交给用户排错。锁屏仅暂停相应桌面路径，不解锁、不保活，继续独立工程。

受阻及时报告六项：①行为/准确版本对象；②输入是否送达及失败层（系统、工具、窗口前置、夹具、产品、决策）；③已试方法与证据；④已授权替代路径；⑤仅阻塞范围及继续工作；⑥下一最小动作。真正需要本人时先入[唯一集中待办](FAILURE_AND_PERMISSION_AUDIT.zh-CN.md)，说明“操作意愿已授权，系统仍要求本人动作”，集中一次给最少步骤、尝试一次既有提示音；无回复不反复鸣响或停止独立工作，不在聊天索要密码/令牌。

持续授权不覆盖未知进程/用户数据破坏、工具禁止的代点、系统绕过、管理员密码/2FA、第三方账号审批或新法律义务、未知费用、D许可证/首发承诺、main合并、商店上传和公开发布。只暂停相应必要决定，不重新询问已经授权的普通开发意愿。

## 副作用、失败与预算

任务预先声明输出、缓存、临时路径与无副作用检查入口。Python语法用tokenize.open读取编码再compile(source, filename, 'exec', dont_inherit=True)，不执行目标、不默认py_compile；不宣称测试进程其他缓存也消失。

| 事件 | 动作 |
| --- | --- |
| 已预写手册、唯一授权缓存/无字节码降级，确认无成功越界、无提权、无未知副作用 | 记录并恢复一次 |
| 未预授权的拒绝或来源不明 | 暂停该动作报Lead，Lead在原授权内判断，不自动要求用户改系统权限 |
| 成功越界、提权、错误仓库、输入破坏、敏感读取、非授权网络、不明副作用或反复撞拒绝 | 立即停止相关写入，保存证据、定位影响 |
| 已批准受控失败夹具 | 按预期验收，不混为真实权限事故 |

Lead每轮返工前先审异常/保护，再看通过数。普通初交＋最多两轮定向修复，之后最多一次有界Lead接管；仍失败停止。改名、换模型、换编号或整理文档不刷新预算。任务记录里的更少余额与明确实验时限继续优先，旧RESULT违规与Lead审核时序不追改合规。普通子执行默认15分钟，特殊长实验须预先明确；不是限制所有构建/模型都15分钟，更不自动授予无限等待。

阻塞立即回报，不无限轮询；无依赖任务可继续，隔离/数据事件先冻结有关写入。取消或规格替代显式记录，旧结果不自动接纳。只处置自己持有的子进程；枚举受阻不提权，不以归档/中断等同外部进程消失。第二独立闭环也阻塞时停止扩大批次。

## 验证、资源与集成

改动类别、最小证据、复用与停止重复统一按[测试政策](TESTING_POLICY.zh-CN.md)，本页保留权限、串行资源、返工与集成责任；不在任务间复制另一套测试矩阵。

Mac默认交Lead管理，无需反复询问空闲/前台；用户用机时让出。重构建、GPU、GUI串行，CPU也受预算约束。不丢未保存作品、不强杀未知进程、不覆盖普通D。本人点击、解锁、设备、试听统一记[集中待办](FAILURE_AND_PERMISSION_AUDIT.zh-CN.md)，返回时集中办理，可播一次既有短音效；不轮询位置、不反复催解锁。锁屏不阻塞独立CPU/代码工作。

GUI使用明确产物、独立项目/偏好；诊断启动器要求D_UI_TEST_SESSION时绑定准确UUID，普通完整App按当前已核验交付入口启动。相同bundle ID/路径不是隔离证据。退出后不调用可能启动应用的getApp/getAXState确认退出，只看自有退出回执或不会启动的库存。GUI失败与替代路径按上节，不绕权限。签名构建沿用原获准配置，不改Team/entitlements/钥匙串；禁签名仅证明编译。Xcode可能登记LaunchServices，不声称系统零变化。XCTest之后真实沙盒验收须普通构建核对签名。

保留SwiftPM构建沙箱，独立scratch/DerivedData及App/MLX依赖检出，不共享可变checkout；Worker受阻报Lead，不自行禁用沙箱。离线参数只代表对应工具控制，不冒称系统断网。真实数值/输出/峰值/取消/重复释放按影响验证，不以cacheBytes零或放宽阈值通过。构建、夹具、真实模型、原生UI、真人、组合与发行分开；未真实验收路径不默认替代已有行为。

停写后Lead审查实际差异/异常/进程/证据，按固定SHA串行合入专属集成树，保留双方历史。已批准且含义明确局部冲突可解决并记录；公共契约/签名/权限/数据/来源不明暂停。每加入任务做相关检查，最后验证具体组合SHA。源若新增已授权提交，在隔离区先同步明确快照再按影响复验；未知漂移不追赶。

源只fast-forward接纳已验组合；前后核对scheme内容/摘要/索引/未暂存状态，显式暂存，不git add -A。不rebase/cherry-pick/squash/amend/reset/restore/stash/清理，不强推，不删工作树/旧证据。2026-10-02起main为唯一公开开发集成线，已批准工作经过相称审阅、检查与已知缺口披露后可正常推进；不以全部发行QA为前置。inference-foundation仅保留旧历史，不要求再经过第二条接纳线。首次更新前保存旧main准确归档及独立备份，后续仍检查自动发布触发与远端漂移；公开开发源码不等于正式发行。允许中止合并仅限开始干净、无他人写入、证据已保存的专属候选树，核验恢复，不用于源或丢新增修改。接入后源入口复验失败如实报已更新而未结案，不自动回退/继续修补来隐藏。

## 来源、恢复与阅读预算

用稳定task_id/run_id关联规格/上下文版本、请求与可观察模型档位、每轮实现/修复/审核人、Lead澄清/反例/解法/实质改写、候选/受测/集成SHA。自定义标签不是Codex认证或质量证明；沿用人类Git身份，不逐函数标签。开发来源与媒体来源分域。实现者自检不代替接纳。

仅记录可核对增量；缓存若已计入输入不重复相加。墙钟、token、Lead完整归因、订阅费用分别记录，未知保留unknown；不重算历史、不套API标价、不凭少样本宣布成本最优。

大日志/样例放工作树外的D-Development/AgentTrials/<task>/<run>，小规格/摘要/许可来源入Git，不公开私人路径/书签/密钥/原素材。每轮新任务以最小充分上下文开始：AGENTS→CURRENT_ACTIONS→相关原则/任务→具体接口；其他ADR/历史/研究按问题读，不全量灌入。没有工具过滤证据时仅称路径导航，不能声称检索排除生效。

恢复检查点：真实HEAD/索引/个人改动、活跃任务与运行身份/目录/权限/自有进程、当前修订、完成/未完成、待决项、下一动作、证据索引。重开或压缩后核对仓库再续，不只信摘要。Lead角色可长期保持，不要求同一物理会话无限增长；交接后可从新上下文开始下一已批准阶段。

历史协作样本、旧预算与规则替代见[历史索引](history/README.md)和[规则整理历史去向表](tasks/D-CONTEXT-RESET-01.md#规则去向)，不重做切换实验，也不因此宣称后续产品已完成。
