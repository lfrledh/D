## 先试一个不需要模型的流程

1. 点 **添加样例 → 文件**，选中“选择图像”节点（操作名称为“项目素材”）。右侧可引用本项目已有图片，或通过“导入”选择 PNG/JPEG；导入成为不可变项目素材，原文件不覆盖。
2. 选中尺寸节点，设置宽高及 `fit`（等比留边）、`fill`（等比裁切）、`stretch`（拉伸）。选中格式节点，选择 PNG 或 JPEG；JPEG 明确选择白/黑底和质量。
3. 顶部点 **导出目录**，用系统目录选择器指定位置。
4. 选中导出节点，点 **运行到这里**。先看计划，再点运行。结果是一个不覆盖已有文件的 `.dexport` 目录，包含真实媒体、配方与回执。
5. 保存，关闭测试项目，再打开。流程、素材、运行记录应恢复；不会自动重新运行。

这些是普通 ImageIO/CoreGraphics 图片处理，不是 AI 超分辨率。界面的像素/格式限制来自本实现，不宣称支持 RAW 或任意色彩工作流。

## 真实图文组合

1. **模型 → 选择文字模型 / 选择图像模型**。选择现有已适配、已安装模型；本机验证使用 Qwen2.5-0.5B-Instruct-4bit 与 FLUX.2 Klein 4B q8。模型默认值不是所有 Mac 的上限；不支持的请求会明确拒绝。
2. 点 **添加样例 → 图文**。修改文字输入、改写指令以及图像参数。示例为 512×512、4 步、guidance 1、seed 42 起、三个候选。再点顶部 **导出目录**，显式选择目的地；每次重开项目后都需要重新选择，不会自动恢复导出目录权限。
3. 选择最终导出节点，点 **运行到这里**并确认计划。改写完成后停在“确认提示”，此时尚未生成图片。
4. 选中确认节点，检查或编辑候选文字，然后明确接受或拒绝。接受后还需点运行记录里的 **恢复**（继续此流程），才执行昂贵的下游生成。
5. 三张图片按顺序生成并分别保存，有独立身份、seed 和请求记录。选择节点展示整个集合；高亮预览不等于采用，需明确选择并确认，再继续尺寸/格式/导出。
6. 一项失败时成功图片保留，可重试失败项；若要使用部分集合，需明确接受部分结果。取消会等待当前计算释放资源，不保证 GPU 瞬间停止。

## 编辑、组合与局部重跑

- 左侧搜索并添加操作；点一个输出端口，再点目标输入端口建立连接。右侧能检查类型、必选/可选与现有连接并断开。缺少输入、已连接但未就绪或集合误接单张图片都会报错，不自动取第一项。
- 可拖动、缩放、折叠、复制、删除节点，撤销/重做编辑。窄窗口支持横向滚动，不因为改变布局而触发模型或使结果过期。
- 改上游输入后，旧成果保留并显示旧输入状态；不会自动重算。**运行到这里**按依赖执行/复用；**仅重跑本步**使用已就绪输入，计划明确告知范围。未重新发布的文稿变化不会进入已有资产。
- **添加样例 → 模板**是另一种可编辑组合，只做 `{{input}}` / `{{other}}` 的字面替换，不执行脚本。“移除文本空行”是独立小程序节点，可接入上述文字流程。
- 在“创作与资料”继续编辑文字后，主动 **发布文稿** 才会产生流程可引用的版本。结果里的 **回到文稿** 新建一份文稿，不覆盖原文。
- 节点结果可查看资产身份、请求/参数、父资产与版本等本地元数据。导出默认不公开提示词；详细本地记录与公开交接包不同。导出内容不包含模型权重、密钥、书签或模型绝对路径。

## 错误与恢复

人工确认/候选选择是持久等待点。确认框中尚未接受的修改也随显式保存和正常关闭保留；读取原文字完成前不能输入。另一任务计算时可继续修改这份草稿，但不会隐式接受。重开后仍需明确决定，不自动采用或恢复推理。异常中断显示“已中断”，由用户选择恢复；不同输入或过期决定不会覆盖新文稿。

保存失败保留已有作品和待保存结果，不用重新生成替代保存重试。文件发布后若目录同步失败，会明确说明结果可能已发布；不要据此删除作品，重新打开核对实际状态。未知流程或节点版本整份只读，并保留原始负载；不自动丢掉不认识的内容。
